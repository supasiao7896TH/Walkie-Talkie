# Local-only IndexedDB ไม่มี cloud sync ใน v1

ผู้ใช้งานจริงคือคนเดียว/เครื่องเดียวเป็นหลัก (ยืนยันจากเซสชัน grilling กับพี่ A) จึงตัดสินใจไม่เพิ่ม Firestore/CLOUD_SYNC_MANAGER หรือระบบ login ใน v1 แม้ URL ที่ deploy จะเข้าถึงได้จากที่ไหนก็ได้ (Cloudflare Workers) — ข้อมูลทั้งหมดอยู่ใน IndexedDB ของ browser เครื่องที่ใช้งานจริงเท่านั้น เพื่อลด scope และความซับซ้อนที่ไม่จำเป็น แลกกับความเสี่ยงที่ข้อมูลหายถ้าล้าง cache/เปลี่ยนเครื่อง จึงต้องมีฟีเจอร์ Export/Import Excel เป็นทางสำรอง (backup) คู่กันเสมอ ถ้าจำนวนผู้ใช้งานจริงเพิ่มขึ้นในอนาคต ค่อยพิจารณาย้ายไป Firestore
