# Inspection เก็บเป็นประวัติ append-only แทน overwrite สถานะล่าสุด

ชีต Excel ต้นแบบเก็บสถานะ Normal/Abnormal แบบเดือนต่อเดือน (เขียนทับของเดิม) แต่พี่ A ยืนยันในเซสชัน grilling ว่าต้องการดูย้อนหลังได้ว่าแต่ละเดือนอาการเป็นอย่างไร ไม่ใช่แค่สถานะปัจจุบัน จึงออกแบบ `inspections` เป็นตารางแบบ append-only (1 record ต่อ target ต่อเดือน ไม่เคย overwrite) แล้วคำนวณ "สถานะล่าสุด" เป็นค่า derived จาก record ที่มี `yearMonth` ล่าสุดเสมอ แทนที่จะเก็บ field สถานะซ้ำไว้ในตัว Radio/Accessory เอง — แลกกับพื้นที่เก็บข้อมูลที่มากขึ้นเรื่อยๆ ตามอายุการใช้งาน ซึ่งยอมรับได้เพราะเป็นข้อความสั้นๆ ไม่ใช่ไฟล์ขนาดใหญ่
